# Random Forest & Alzheimer's clinical data experiment

Testing a Random Forest model for early identification of likely Alzheimer's diagnosis. 

Based on widely-available (to physicians) clinical data, and an exercise in representation design: the operatic nature of the Random Forest (the same reason its features explainably decompose, they are algebraically combined) makes it an exceptional architectural choice for working with distinct orders of features.
